# backtest

单标的研究回测，读策略已经算好的目标权重。权重可以是 0 到 1 之间的建议仓位。

跟单视图锁定为 `next_open`。并排表的第一行是这个假设，收盘成交只作对照。

- `next_open`：信号在收盘确定，成交价用下一交易日开盘。隔夜缺口算旧仓位，开盘后的日内涨跌算新仓位。
- `close`：信号当天收盘价成交，收益从下一根收盘到收盘才开始算。
- `next_open_stop`：只有止损改成下一交易日开盘退出。触发仍看收盘，不是盘中。其他信号仍按收盘假设。

另外报告收益、最大回撤（正数）和换手。半仓买进再卖出，换手是 1。

没有滑点、佣金、印花税，也不处理涨跌停和停牌。价格必须为正。这里的成交只是价格假设，不记录真实成交，也不和实际回报对照。
