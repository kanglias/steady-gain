# orders

把信号表导出成 CSV 和 Markdown，方便人工对照后到券商客户端自己下单。

列里包括建议仓位（可以小于满仓）、持有天数、当前腿浮动盈亏、连续亏损段数、距上次交叉的交易日，以及「短持翻脸」。这些是研究字段，不是成交回报。

`orders/banned.txt` 里一行一个 6 位代码。清单中只要出现这些代码，导出会直接拒绝，并且不会写文件。默认文件只有注释，没有预置禁投代码。写入和核对拒绝的步骤见仓库 README 的「先写禁投名单，再确认导出会拒绝」。

连续亏损达到阈值，或短持翻脸卖出反复出现时，清单会写「建议暂停加仓」，并写明当前是仍持有还是空仓，避免把提示看成新开仓。这句话只出现在 Markdown 开头的汇总，以及该代码最新的一行上，不会盖到更早的买入。原因列默认保留止损和交叉说明。

本仓库不做这些事：

- 券商 API
- 自动下单、条件单、无人值守交易
- 成交回报接入

不要在这个包里添加提交委托的函数。
